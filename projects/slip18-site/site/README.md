# Slip 18 Landing Page MVP

This is a coded static landing page for Slip 18.

## How to preview locally

Open `index.html` in a browser.

## What to edit first

1. Replace `hello@slip18.ai` with your real email once domain/email is chosen.
2. Replace CTA links with a real calendar or intake form.
3. Add real proof only after it exists.
4. Keep pricing off the public page for v1.

## Deployment options

This can be deployed as static HTML/CSS on Netlify, Vercel, GitHub Pages, Cloudflare Pages, or migrated later into Astro, Next.js, or another framework.

## V1 rule

The page exists to support sales conversations and book Workflow Diagnostics. Do not overbuild it before getting market feedback.
