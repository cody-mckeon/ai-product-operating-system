# Website Build Spec v0.1

## Goal

Build a simple, credible landing page that supports sales conversations and drives Workflow Diagnostic inquiries.

## Page type

Single-page marketing site.

## Technical recommendation

Start with a coded static landing page. Keep the first version simple enough to deploy quickly and easy to refactor later.

## Required sections

- Navigation
- Hero
- Problem statement
- Outcome cards
- Example agents
- Process
- Who we help
- Why Slip 18
- Final CTA
- Footer

## Avoid for v1

- Fake testimonials
- Fake logos
- Fake case studies
- Complex backend
- Login portal
- Blog
- Overbuilt animation
- Pricing table

## Success criteria

- Page clearly explains what Slip 18 does
- Page feels specific to hospitality
- Page has a clear CTA
- Page can be used in sales pitches
- Page can be iterated by Hermes
